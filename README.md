## 注意事项

1. **全内容文档有内部标注规则**：标红为待修订内容、**黄底内容暂不对外**。预览版未收录黄底内容；引用该文档内容时注意甄别。
2. **文档每周一 8:30 阶段性消红更新**，议程和嘉宾会滚动修订。建议每周同步一次页面内容（重新跑上面的 `lark-cli` 命令拉取最新版对比即可）。
3. 本预览版是纯静态单文件，**无后端、无真实报名/支付功能**，按钮均为演示性质。正式官网开发请依据 `02_技术搭建预案.md` 的架构与优先级推进：
   - **会前必做**：统一身份与 H5 路由、轻量报名（信息/选座/缴费）、问卷与身份关联、学习地图、学习护照与未来币闭环、三类票种及展厅门禁、投票提问、AI 智能体体验、实时字幕、用户协议与压测
   - **优先复用/采购**：报名支付、外部问卷、既有一体化平台能力、科大讯飞企业版等
   - **暂不立项**：价值地图 H5、知识接力数字化、同频人匹配、主论坛无审核 AI 实时画像
4. 仓库为**公开仓库**（为了 GitHub Pages 免费托管），请勿把内部价格策略、未官宣嘉宾等敏感信息提交进去。
5. 去年官网为 Vue SPA（eicc.dett.cn），路由结构已摸清备查（/agenda /SignUp /Guide /ProductCenter /Summary 等），API 域名 admin-eicc.dett.info——正式开发如需对接旧系统可参考。
